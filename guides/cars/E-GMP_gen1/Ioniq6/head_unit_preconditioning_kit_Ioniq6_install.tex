\section{Introduction}
  The purpose of this guide is to illustrate step-by-step instructions for installing the head unit preconditioning kit, or just the head unit man-in-the-middle (MITM) harness, shown in Figure \ref{subfig:overview:harness}. In section \ref{sect:2}, we describe the trim removal process to access the head unit. In section \ref{sect:3}, we describe the process of plugging in the harness. In section \ref{sect:4}, we show attachment of the OBD port and how to plug in the microcontroller. 

Necessary tools:
\begin{enumerate}
  \item 10mm socket or adjustable wrench for 12V battery (not included)
  \item Trim removal tools (included if selected)
\end{enumerate}

Kit components:
\begin{enumerate}
  \item Head unit harness
  \item WiCAN
  \item 70mm OBD mount bracket
  \item 70mm double-sided tape (two pieces included for redundancy)
  \item 4 zip ties
\end{enumerate}
  
\section{Step 1: Remove 12V Negative Terminal} \label{sect:1}
First, always disconnect the 12V battery before removing any electrical connectors! Removing a live electrical connector could cause a discharge and destroy a connector or ECU in your car.

Step-by-step instructions:
\begin{enumerate}
  \item Open hood % (Figure \ref{subfig:12V:hood})
  \item Open frunk  (Figure \ref{subfig:12V:frunk})
  \item Remove panel covering 12V % (Figure \ref{subfig:12V:panel})
  \item Loosen nut on negative side with a 10mm socket % (Figure \ref{subfig:12V:nut})
  \item Remove negative terminal % (Figure \ref{subfig:12V:terminal})
\end{enumerate}

\section{Step 4: OBD Mount} \label{sect:4}
In this step, we mount the OBD end of the harness securely and plug in the WiCAN. 

Step-by-step instructions:
\begin{enumerate}
  \item Thread OBD end over head unit mount bracket (Figure \ref{subfig:obd:thread_obd})
  \item Re-mount head unit. (Figure \ref{subfig:trim:HU_screws})
  \item Plug OBD female into provided bracket, if not already mounted
  \item Use double-sided tape to mount bracket to a flat trim surface
  \item Use zip ties to attach harness to other wires and mount points 
  \item While holding bracket, plug in WiCAN (Figure \ref{subfig:obd:wican})
\end{enumerate}

\section{Step 5: Clean up} \label{sect:5}
Reverse the trim removal steps. Make sure trim clips are aligned, and then firmly pop the trim panels back into place. Reconnect 12V battery negative terminal. The WiCAN should immediately show a blue light.

\subsection{WiCAN setup}
The WiCAN by default provides a WiFi access point. Look for a network named \texttt{WiCAN\_xxxxxxx}, where \texttt{xxxxxxx} is the device ID of your unit, and connect to it with the default password \texttt{@meatpi\#}. From a phone, the network can take a few seconds to appear, and your phone will warn you that it has no internet access; stay connected anyway. Then open \href{http://192.168.80.1}{http://192.168.80.1} in a browser to reach the configuration interface. (A WiCAN Pro, not officially supported, uses \href{http://192.168.0.10}{http://192.168.0.10} instead.)

In the ``Settings'' tab, change the access point password. With the default password, anyone within WiFi range of your car who knows the default password could unlock your car (yes, this feature is coming!). If you leave the WiCAN in access point mode, we also suggest disabling BLE for now.

Optionally, the WiCAN can be configured in station mode to join your home WiFi so that you can reach it from inside the house. In the ``Settings'' tab, set ``Mode'' to ``AP+Station'', enter your network's ``SSID'' and ``Password'', and press ``Submit changes''. The WiCAN keeps broadcasting its own access point, so you cannot lock yourself out this way. However, access point mode in ``AP+Station'' can be a bit finicky, so we recommend AP only unless you're using Home Assistant or similar to grab data from your car. The ``Status'' tab then shows the ``Station IP'' your router assigned, which is the address to use from your home network.

The full WiCAN WiFi documentation is at \href{https://meatpihq.github.io/wican-fw/config/wifi}{https://meatpihq.github.io/wican-fw/config/wifi}.
