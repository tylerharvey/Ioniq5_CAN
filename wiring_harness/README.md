# What is this?

These are drawings of wiring harnesses manufactured for and sold by our shop. At the moment, all drawings are copies **as sent to the manufacturer** and not **as-manufactured**, except [the two CAN interfaces ICU-H harness](./ICU-H_dongle_separable_2CAN_001-2.yml). This one has **as-manufactured** conector part numbers in places where the drawing allowed for choice by the manufacturer. We will eventually include both copies of each drawing, but need to find the least confusing way to organize this.

# Pinouts

These wiring harnesses use the Hyundai service manual connector pinout numbering scheme. In the case of the OBD port, this is backwards from the most commonly used numbering scheme, including the numbering scheme we use for labeling WiCAN pins, which adopt from the WiCAN designer. Please keep this in mind and translate pin numbers appropriately. We will add some helper documentation on this when possible.
